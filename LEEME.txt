LITTLE FOCUS — EXTENSIÓN PARA CHROME (v1.1.0)

QUÉ INCLUYE
- Conserva el temporizador, calendario, rachas, notas, temas, sonidos, ajustes y listas de YouTube.
- Las listas permiten crear y eliminar listas, añadir enlaces y reproducir vídeos con anterior/siguiente.
- Los cambios se guardan localmente y, al conectar una cuenta, se sincronizan automáticamente con Supabase.
- Se ha separado el JavaScript de index.html en archivos externos para que funcione con la política de seguridad de Manifest V3.
- El reproductor usa el iframe oficial de YouTube sin cargar una API JavaScript externa bloqueada por la política de extensiones.

INSTALACIÓN DE LA EXTENSIÓN
1. Extrae este ZIP en una carpeta.
2. Abre chrome://extensions y activa Modo de desarrollador.
3. Pulsa Cargar descomprimida y selecciona la carpeta que contiene manifest.json.
4. Si ya tenías una versión anterior, puedes cargar esta carpeta sobre la anterior o quitar la anterior primero.

ACTIVAR LA NUBE (REQUERIDO UNA SOLA VEZ)
La nube no se puede activar automáticamente sin una cuenta de almacenamiento. Esta versión utiliza Supabase (plan gratuito disponible), y requiere crear tu propio proyecto:
1. Crea un proyecto en https://supabase.com/.
2. En el panel del proyecto, copia Project URL y la clave pública anon/publishable (Settings > API Keys).
3. Abre SQL Editor en Supabase, pega el contenido completo de supabase-setup.sql y pulsa Run.
4. Abre Little Focus en una ventana completa y pulsa el botón ☁ Nube.
5. Introduce Project URL, la clave pública, tu correo y una contraseña. Pulsa Crear cuenta.
6. Si Supabase tiene activada la confirmación por correo, confirma el correo recibido y vuelve a ☁ Nube para iniciar sesión.

A partir de ahí, Little Focus sincroniza automáticamente los cambios. Para usar los mismos datos en otro ordenador, instala la extensión, introduce la misma URL y clave pública y entra con la misma cuenta.

IMPORTANTE SOBRE SEGURIDAD
- Utiliza exclusivamente la clave pública anon/publishable del proyecto.
- NUNCA introduzcas ni publiques la clave service_role.
- La tabla usa Row Level Security: cada usuario solo puede leer y modificar su propia fila.
- La URL y clave pública se guardan en el navegador; la contraseña no se guarda en Little Focus. La sesión se conserva para mantener la sincronización.
- El primer inicio de sesión restaura la copia de nube si ya existe; si no existe, sube los datos locales.
- La sincronización requiere conexión a Internet. Sin conexión, Little Focus sigue guardando localmente y vuelve a sincronizar cuando pueda.

YOUTUBE
- Pega enlaces youtube.com/watch, youtu.be, shorts, live o embed en Mis listas.
- La reproducción se realiza dentro del reproductor incrustado oficial de YouTube; algunas restricciones del vídeo o de YouTube pueden impedir su reproducción integrada.
